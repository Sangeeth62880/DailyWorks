# Project Title
# DailyWorks 🛠️

DailyWorks is a web platform designed to connect recruiters and job seekers for **daily wage and short-term jobs** without intermediaries.  
It focuses on simplicity, speed, and accessibility for real-world use cases such as catering, events, helpers, and temporary work.

---

## 🚀 Features

- Post and discover **daily / part-time jobs**
- Direct connection between recruiter and worker
- No middlemen or agencies
- Simple and intuitive user interface
- Scalable backend architecture

---

## 🧠 Motivation

Most existing job portals are built for long-term employment and are overcomplicated for daily wage work.  
DailyWorks aims to solve this gap by providing a **lightweight, practical platform** focused on short-term job opportunities.
